# Intro to Matplotlib

This repository contains the presentation materials for the Intro to Matplotlib (Python graphing) workshop conducted on 11/10/2026.

### Workshop Overview

The workshop shows how to turn data into clear graphs with Python and Matplotlib. Attendees read a spreadsheet with pandas, made a first line plot, switched it to a scatter plot, and customized it with color by a third variable, marker shapes, a background color and a grid. It ends with a tour of other graph types and how to pick one that fits the data.

### Code

The `code` folder has the script and the sample data from the workshop:

- `matplotlib_workshop.py`: the workshop script. The commented lines are the customizations from the slides; uncomment one at a time to try them.
- `Basic-SampleDataset.xlsx`: the sample data the script reads.

It needs Python with `matplotlib`, `pandas` and `openpyxl` (`pip install matplotlib pandas openpyxl`). From the `code` folder, run `python matplotlib_workshop.py`.
